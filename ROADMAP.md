# Roadmap

This roadmap describes areas of work, not delivery dates. Priorities may change based on maintainer capacity and community feedback.

## Available now

- Framework-agnostic UI engineering standards and examples.
- Existing-project discovery and greenfield architecture guidance.
- Project baseline, review checklist, and agent adapter example.
- A quick-start prompt and sample discovery-to-baseline output.

## Next areas to explore

- Try the onboarding flow on a few public projects with different frontend stacks and publish the findings.
- Document which agent adapters have been tried and what required adjustment.
- Improve the quick start from feedback by first-time users.

## Possible later work

- A thin, optional installable skill that points to the canonical standards and guides project discovery.
- A small, transparent evaluation rubric for component reuse, token consistency, accessibility states, and scope control.
- Additional examples for greenfield architecture decisions and project baselines.

Open an issue to suggest a use case, report friction, or propose a roadmap change.
