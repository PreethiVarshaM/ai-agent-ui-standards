# Changelog

Notable changes to AI Agent UI Standards are recorded here.

## [0.1.0] - 2026-11-24

Initial public release.

### Included

- Framework-agnostic UI engineering standards for architecture, design systems, components, styling, accessibility, responsive design, code quality, and optional frontend integration.
- An evidence-based project discovery workflow for established and greenfield applications.
- An adoption guide, project UI baseline, review checklist, and short agent adapter example.
- A copyable read-only quick-start prompt and sample discovery-to-baseline report.
